## 📖 Описание

**Lots of Food** - это масштабный мод для Minecraft, который добавляет более **150 новых продуктов питания**, напитков и декоративных блоков! От простых фруктов и овощей до сложных блюд, десертов и напитков - этот мод значительно расширяет кулинарные возможности Minecraft.

### ✨ Основные особенности

- 🍕 **150+ новых продуктов питания**
- 🍰 **Разнообразные десерты**: торты, кексы, пончики, мороженое
- 🥤 **Напитки**: соки, кофе, чай, молочные коктейли, алкоголь
- 🍖 **Новые виды мяса и рыбы**
- 🥗 **Супы, салаты и готовые блюда**
- 🧱 **Декоративные блоки**: шоколадные, карамельные, сахарные
- 🎨 **Полностью кастомные текстуры**
- 🌍 **Поддержка множества языков**

## 🚀 Быстрый старт

### Требования

- **Minecraft**: 1.20.1
- **Forge**: 47.3.0 или выше
- **Java**: 17 или выше

### Установка для игроков

1. Установите [Minecraft Forge 1.20.1](https://files.minecraftforge.net/)
2. Скачайте последнюю версию мода из [Releases](../../releases)
3. Поместите JAR-файл в папку `mods/`
4. Запустите Minecraft с профилем Forge

### Сборка из исходников

```bash
# Клонируйте репозиторий
git clone https://github.com/yourusername/lotsoffood.git
cd lotsoffood

# Соберите мод
./gradlew build

# JAR-файл будет в build/libs/
```

Подробная инструкция: [STEP_BY_STEP_GUIDE.md](STEP_BY_STEP_GUIDE.md)

## 🎮 Игровой процесс

### Крафт

Большинство продуктов можно скрафтить из базовых ингредиентов Minecraft и новых продуктов мода. Примеры:

```
Шоколад = Какао-бобы + Сахар
Пицца = Помидоры + Сыр + Мясо + Пшеница
Сэндвич = Хлеб + Сыр + Хлеб
```

### Готовка

Некоторые продукты нужно приготовить в печи:
- Сырой бекон → Жареный бекон
- Сырая рыба → Жареная рыба
- Сырое мясо → Жареное мясо

### Креативная вкладка

Все предметы мода находятся в отдельной креативной вкладке **"Lots of Food"** для удобного доступа.

## 🛠️ Для разработчиков

### Структура проекта

```
lotsoffood/
├── src/main/java/pda/lotsoffood/
│   ├── LotsOfFood.java          # Главный класс мода
│   └── init/
│       ├── ModItems.java        # Регистрация предметов
│       ├── ModBlocks.java       # Регистрация блоков
│       └── ModCreativeTabs.java # Креативные вкладки
├── src/main/resources/
│   ├── META-INF/mods.toml       # Метаданные мода
│   ├── pack.mcmeta              # Метаданные ресурспака
│   ├── assets/lotsoffood/       # Ресурсы (модели, текстуры, переводы)
│   └── data/lotsoffood/         # Данные (рецепты, loot tables)
└── build.gradle                 # Конфигурация сборки
```

### API и совместимость

Мод использует современный Forge API для 1.20.1:
- `DeferredRegister` для регистрации предметов и блоков
- `RegistryObject` для безопасных ссылок
- `CreativeModeTab.Builder` для креативных вкладок
- `FoodProperties.Builder` для свойств еды
