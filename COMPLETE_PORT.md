## 🎮 Новые функции в игре

### 1. Кокос как оружие
```
/give @p lotsoffood:noixdecoco
```
- Возьмите кокос в руку
- Нажмите правую кнопку мыши
- Кокос полетит как снежок
- При попадании наносит 4 урона

### 2. Дроп с мобов
Убивайте мобов и получайте еду:
- **Свиньи** → Бекон (50%)
- **Коровы** → Сыр (30%)
- **Лошади** → Конина (50%)
- **Зомби** → Очищенное мясо (10%)

### 3. Кокосовые пальмы
- Генерируются на пляжах
- Редкие (1 на 32 чанка)
- Можно найти кокосы

### 4. Золотая рыба
```
/give @p lotsoffood:poissonorcru    # Сырая
/give @p lotsoffood:poissonorcuit   # Приготовленная
```
- **Сырая:** Удача I (30 сек)
- **Приготовленная:** Удача II (60 сек) + Регенерация II (20 сек)
- Имеет золотое свечение

### 5. Конфеты с вариантами
```
/give @p lotsoffood:papillote
```
- 15 разных текстур
- Случайная текстура при крафте
- Хранится в NBT данных

## 🚀 Как использовать

### Сборка
```bash
./gradlew build
```
**Результат:** `build/libs/lotsoffood-1.20.1-1.0.0.jar`

### Тестирование
```bash
./gradlew runClient
```

### Установка
1. Установите Forge 1.20.1 (47.3.0+)
2. Скопируйте JAR в `.minecraft/mods/`
3. Запустите Minecraft

